# goit-pythonweb-hw-10

REST API для управління особистими контактами з JWT-авторизацією,
підтвердженням email та завантаженням аватарів у Cloudinary.

## Можливості

- Реєстрація користувачів з унікальними username та email.
- Хешування паролів за допомогою Argon2.
- Вхід за username і паролем, отримання JWT access_token.
- Підтвердження email через посилання в листі.
- Повторне надсилання листа підтвердження.
- CRUD контактів із доступом лише до власних записів.
- Пошук за ім’ям, прізвищем та email.
- Пошук днів народження на найближчі 7 днів.
- Обмеження GET /me: 5 запитів на хвилину з одного IP.
- Налаштування CORS через змінні середовища.
- Оновлення аватара через Cloudinary.
- Запуск API, PostgreSQL, Redis і Mailpit через Docker Compose.

## Технології

Python 3.14, FastAPI, SQLAlchemy, PostgreSQL, Alembic,
Pydantic, PyJWT, pwdlib, SlowAPI, Redis, aiosmtplib, Cloudinary.

## Запуск

Потрібні Git і Docker з підтримкою Docker Compose.
Команди наведено для PowerShell.

### 1. Клонування репозиторію

```powershell
git clone https://github.com/Matvieienko/goit-pythonweb-hw-10.git
cd goit-pythonweb-hw-10
```

### 2. Налаштування середовища

```powershell
Copy-Item .env.example .env
```

У `.env`:

- Задайте власний `JWT_SECRET` — випадковий секрет довжиною щонайменше 32 символи.
- Заповніть `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` з облікового запису Cloudinary.
- За потреби змініть реквізити PostgreSQL і дозволені `CORS_ORIGINS`.

Для генерації JWT_SECRET за наявності Python:

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

Скопіюйте результат у `.env`. Справжні секрети не слід додавати до `.env.example` або Git.

Початкові реквізити PostgreSQL у прикладі призначені для локального навчального запуску.

### 3. Збірка та запуск

Запустіть Docker Desktop, потім виконайте:

```powershell
docker compose up -d --build
```

Під час запуску API автоматично застосовуються міграції Alembic.

Перевірка стану:

```powershell
docker compose ps
docker compose logs --tail=50 api
```

### 4. Адреси сервісів

| Сервіс | Адреса |
|---|---|
| Swagger UI | http://127.0.0.1:8000/docs |
| ReDoc | http://127.0.0.1:8000/redoc |
| Mailpit | http://localhost:8025 |
| PostgreSQL з комп’ютера | 127.0.0.1:5434 |
| Redis з комп’ютера | 127.0.0.1:6380 |

Cloudinary є зовнішнім сервісом і потребує доступу до інтернету.

## Перевірка через Swagger

1. Створіть користувача через POST /auth/register.
2. Відкрийте Mailpit і перейдіть за посиланням у листі підтвердження.
3. У Swagger натисніть Authorize та введіть username і password.
4. Використовуйте маршрути контактів і профілю.

Mailpit перехоплює тестові листи локально: вони не надходять до справжніх поштових скриньок.

Приклад реєстрації:

```json
{
  "username": "demo_user",
  "email": "demo.user@example.com",
  "password": "DemoPassword123"
}
```

Пароль у прикладі призначений лише для тестування.

## Маршрути API

| Метод | Маршрут | Призначення |
|---|---|---|
| POST | /auth/register | Реєстрація, відповідь 201 |
| POST | /auth/login | Вхід, отримання access_token |
| GET | /auth/verify-email | Підтвердження email |
| POST | /auth/resend-verification | Повторне надсилання листа |
| GET | /me | Дані поточного користувача |
| PATCH | /me/avatar | Оновлення аватара |
| POST | /contacts/ | Створення контакту, відповідь 201 |
| GET | /contacts/ | Список і пошук контактів |
| GET | /contacts/birthdays | Найближчі дні народження |
| GET | /contacts/{contact_id} | Отримання контакту |
| PUT | /contacts/{contact_id} | Повне оновлення контакту |
| DELETE | /contacts/{contact_id} | Видалення контакту, відповідь 204 |

Вхід приймає username і password у тілі запиту у форматі
application/x-www-form-urlencoded.

Access-токен передається в заголовку:

```text
Authorization: Bearer <access_token>
```

Строк дії access-токена визначає JWT_ACCESS_TOKEN_EXPIRE_MINUTES.
Після його завершення потрібно увійти повторно.

## Правила доступу та валідації

- Операції з контактами потребують JWT і підтвердженого email.
- GET /me та PATCH /me/avatar потребують JWT.
- Чужі контакти недоступні для читання, оновлення та видалення: сервер повертає 404.
- Email контакту унікальний у межах одного власника.
- Повторна реєстрація з тим самим email або username повертає 409.
- Неправильні облікові дані або недійсний access-токен повертають 401.
- Непідтверджений email при зверненні до контактів повертає 403.
- Перевищення ліміту GET /me повертає 429.
- Паролі та їхні хеші не повертаються у відповідях API.

Аватари: JPEG, PNG або WebP, до 5 МБ.
Cloudinary обробляє зображення до розміру 250 × 250 пікселів.

## Пошук контактів

GET /contacts/ підтримує query-параметри:

- first_name, last_name, email — пошук за частиною рядка без урахування регістру.
- skip — кількість пропущених записів, типово 0.
- limit — розмір сторінки від 1 до 100, типово 100.

Кілька фільтрів застосовуються одночасно.

Період днів народження включає сьогодні та наступні шість днів
за датою сервера. Перехід між роками враховано.
29 лютого не переноситься на інші дати у невисокосні роки.

## Перевірені сценарії

Ручні перевірки виконано через Swagger UI та curl:

- Реєстрація користувача — 201.
- Повторний email — 409.
- Неправильний пароль і неіснуючий користувач — 401.
- Отримання листа в Mailpit і підтвердження email.
- Заборона доступу до контактів до підтвердження email — 403.
- Відсутність чужих контактів у списку.
- Читання, зміна та видалення чужого контакту — 404.
- Перевищення ліміту GET /me — 429.
- Завантаження аватара та відкриття зображення з Cloudinary.
- CORS preflight із дозволеного джерела — 200.
- Запуск API через Docker Compose та читання збереженого профілю.

## Зупинка та повторний запуск

Зупинка:

```powershell
docker compose stop
```

Повторний запуск:

```powershell
docker compose up -d
```

Після змін коду:

```powershell
docker compose up -d --build
```

Дані PostgreSQL зберігаються в іменованому Docker-томі.
Команда docker compose down -v видаляє цей том і дані.

Поштові повідомлення Mailpit у поточній конфігурації не мають
окремого тому та можуть бути втрачені при перестворенні контейнера.
